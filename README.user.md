## 隐私与安全

- 插件运行在你的浏览器中,可以读取当前会话的可见内容;不能读取 API Key、附件原件与其他插件的数据。
- 插件脚本 `plugin.js` 带有作者签名,用来确认它确实来自作者本人;签名只覆盖这个脚本,插件的元数据由插件合集校验。
- 只安装来自你信任的来源的插件。
- 插件的数据保存在本地浏览器中,卸载插件时一并清除。
- 签名校验不通过时,聊天网页会给出提示,建议从可信来源重新安装。

## 隐私与安全

- 插件运行在你的浏览器中,可以读取当前会话内容与 API Key。
- 插件产物带有作者 Ed25519 签名,用于确认产物来自作者本人。
- 只安装来自你信任的来源的插件。
- 插件的数据保存在本地浏览器中,卸载插件时一并清除。
- 签名不通过的插件会被提示,建议重新下载。
